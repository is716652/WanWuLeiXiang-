## ✨ 功能概述

河图洛书是中国古代数理哲学的基础，展示了天地生成之数与九宫数理结构。

### 🎯 核心内容

#### 1️⃣ 河图 - 天地生成之数

**河图口诀：**
- 天一生水，地六成之
- 地二生火，天七成之
- 天三生木，地八成之
- 地四生金，天九成之
- 天五生土，地十成之

**河图数理结构：**
```
         七(火成)
          
    三         五       四
   (木生)    (土生)    (金生)
              十
             (土成)
              
    八         一       九
   (木成)    (水生)    (金成)
              六
             (水成)
              
         二(火生)
```

**河图五行配置：**
- **北方水**：一六 → 坎卦
- **南方火**：二七 → 离卦
- **东方木**：三八 → 震巽
- **西方金**：四九 → 兑乾
- **中央土**：五十 → 中宫

**河图象数原理：**
- 生数：1, 2, 3, 4, 5（奇数为天，偶数为地）
- 成数：6, 7, 8, 9, 10（生数+5）
- 天数之和：1+3+5+7+9 = 25
- 地数之和：2+4+6+8+10 = 30
- 天地之数：25+30 = 55（大衍之数）

#### 2️⃣ 洛书 - 九宫数理

**洛书口诀：**
- 戴九履一，左三右七
- 二四为肩，六八为足
- 五居中央，纵横皆十五

**洛书九宫图：**
```
  4(巽)    9(离)    2(坤)
  东南     正南     西南

  3(震)    5(中)    7(兑)
  正东     中宫     正西

  8(艮)    1(坎)    6(乾)
  东北     正北     西北
```

**洛书九宫配置：**
| 宫位 | 卦象 | 方位 | 五行 |
|------|------|------|------|
| 一宫 | 坎 | 正北 | 水 |
| 二宫 | 坤 | 西南 | 土 |
| 三宫 | 震 | 正东 | 木 |
| 四宫 | 巽 | 东南 | 木 |
| 五宫 | 中 | 中宫 | 土 |
| 六宫 | 乾 | 西北 | 金 |
| 七宫 | 兑 | 正西 | 金 |
| 八宫 | 艮 | 东北 | 土 |
| 九宫 | 离 | 正南 | 火 |

**洛书数理特点：**
- **纵横斜和**：任意一条线三数之和均为15
  - 横：4+9+2=15, 3+5+7=15, 8+1+6=15
  - 竖：4+3+8=15, 9+5+1=15, 2+7+6=15
  - 斜：4+5+6=15, 2+5+8=15
- **奇偶排列**：四角为偶（2,4,6,8），四正为奇（1,3,7,9）
- **对宫之和**：相对两宫数字之和为10（如1+9=10, 2+8=10）
- **中央为5**：五居中央，土德中和
- **后天八卦**：洛书配后天八卦方位
