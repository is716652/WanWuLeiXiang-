# 汉代象数易学功能说明

## 📚 功能概述

**汉代象数易学**是一个专门的功能模块，整合了汉代京房易学体系的核心内容，包括八宫卦序、纳甲配置、卦气值日和重卦法表等四大核心功能。

## 🎯 模块结构

### 🏛️ 汉代象数易学导航页
- **功能**：统一入口，整合四大子功能
- **设计**：紫色系渐变主题，体现汉代易学的庄重感
- **特点**：清晰的功能分类和详细说明

### 📊 四大核心功能

#### 1. 京房八宫卦 🔮
- **理论基础**：京房易学的世应理论
- **功能特色**：
  - 八宫卦序完整展示
  - 世应爻位标注
  - 六爻占卜基础知识
  - 卡片式交互设计

#### 2. 京房重卦法表格 📋
- **理论基础**：卦变规律的系统化
- **功能特色**：
  - 完整的重卦法表格
  - 阴阳消长规律展示
  - 卦变过程可视化
  - 表格式数据呈现

#### 3. 纳甲配置表 ⚡
- **理论基础**：天干地支与八卦的对应
- **功能特色**：
  - 八卦纳甲完整规则
  - 天干地支配置详解
  - 五行属性标注
  - 记忆口诀辅助

#### 4. 卦气值日 📅
- **理论基础**：基于"六日七分"的时间易学
- **功能特色**：
  - 31年完整覆盖（2010-2040）
  - 冬至起始的卦气轮值
  - 60卦完整值日表
  - 节气对应关系
