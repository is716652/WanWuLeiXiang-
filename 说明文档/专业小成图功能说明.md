# 小成图专业版功能说明

## 📋 功能概述

小成图专业版是在基础起卦功能上扩展的高级预测系统,完全符合ArkTS开发规范,实现了传统小成图预测法中的核心功能。

## 🎯 核心功能模块

### 1. 装卦系统

**四盘数据生成**:
- **天盘**: 基于上卦排列,代表天时、外部环境
- **地盘**: 基于下卦排列,代表地利、内在条件  
- **人盘**: 天地相合,代表人事变化
- **神盘**: 归藏变换,代表隐藏信息

**技术实现**:
```typescript
// 使用Map存储,完全符合ArkTS规范
interface ZhuangGuaResult {
  tianPan: Map<string, string>;
  diPan: Map<string, string>;
  renPan: Map<string, string>;
  shenPan: Map<string, string>;
}
```

### 2. 四象占法

**分析维度**:
- 父母运势
- 子女情况
- 婚姻状况
- 事业发展
- 财运走势
- 健康状态
- 阳宅风水
- 阴宅风水

**判断标准**:
- ✅ **吉**: 同宫和谐
- ❌ **凶**: 宫位冲突
- 🔄 **生**: 五行相生
- ⚔️ **克**: 五行相克

### 3. 用神取用

**核心用神**:
- 父亲: 乾宫
- 母亲: 坤宫
- 子女: 艮宫
- 婚姻: 兑宫
- 事业: 震宫
- 财运: 巽宫
- 健康: 坎宫/离宫

**分析要素**:
```typescript
interface YongShenPosition {
  宫位: string;    // 用神所在宫位
  落宫: string;    // 落入的卦宫
  四象: SiXiangType; // 吉凶判断
}
```

## 🏗️ 架构设计

### 设计原则

1. **完全符合ArkTS规范**
   - ❌ 无索引签名 `[key: string]: T`
   - ❌ 无解构赋值 `const [a, b] = arr`
   - ❌ 无动态索引访问 `obj[key]`
   - ✅ 使用Map替代动态对象
   - ✅ 明确接口定义
   - ✅ 实例方法优先

2. **模块化设计**
   - `XiaoChengTuProfessional.ets`: 核心算法类
   - `XiaoChengTuProfessionalPage.ets`: 专业预测页面

3. **数据结构优化**
   ```typescript
   // 使用Map存储动态数据
   private baGuaOrder: Map<string, number>;
   
   // 明确定义所有接口
   export interface ZhuangGuaResult {
     tianPan: Map<string, string>;
     // ...
   }
   ```

### 核心类方法

**XiaoChengTuProfessional类**:

```typescript
class XiaoChengTuProfessional {
  // 装卦
  performZhuangGua(shangGua, xiaGua): ZhuangGuaResult

  analyzeSiXiang(zhuangGua): SiXiangResult

}
```

## 🎓 预测方法

### 五行生克

**相生关系**:
- 金生水 → 水生木 → 木生火 → 火生土 → 土生金

**相克关系**:
- 金克木 → 木克土 → 土克水 → 水克火 → 火克金

### 八卦五行

| 卦名 | 五行 | 方位 |
|-----|------|------|
| 乾 | 金 | 西北 |
| 兑 | 金 | 西 |
| 离 | 火 | 南 |
| 震 | 木 | 东 |
| 巽 | 木 | 东南 |
| 坎 | 水 | 北 |
| 艮 | 土 | 东北 |
| 坤 | 土 | 西南 |

### 断事要诀

1. **看宫位**: 确定用神所在宫
2. **看落宫**: 判断落入何宫
3. **看四象**: 吉凶生克判断
4. **看五行**: 分析生克关系
5. **综合论**: 整体把握趋势
