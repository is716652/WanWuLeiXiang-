# 焦氏易林起卦功能说明

## 功能概述

基于传统焦氏易林起卦法，实现了现代化的"六爻同时生成法"起卦工具，为用户提供便捷的易学占卜体验。

## 理论基础

### 焦氏易林起卦法
- **历史背景**：焦氏易林是汉代焦延寿所著，是重要的易学占卜典籍
- **核心理念**：通过本卦和之卦的组合，查询对应的林辞获得占验结果
- **现代化改进**：采用"六爻同时生成法"替代传统的六次抛币，提升用户体验

### 六爻同时生成法
基于"叁天两地"而倚数的古法，设计了科学的概率分布：

1. **老阳 (O)** - 变爻，20%概率
   - 阳之极，物极必反
   - 在之卦中转换为少阴

2. **少阴 (--)** - 稳定爻，29%概率
   - 阴中生阳，常态稳定
   - 在之卦中保持不变

3. **少阳 (—)** - 稳定爻，30%概率
   - 阳中生阴，常态稳定
   - 在之卦中保持不变

4. **老阴 (X)** - 变爻，21%概率
   - 阴之极，物极必反
   - 在之卦中转换为少阳

## 功能特性

### 1. 起卦方式
- **设置问题起卦**：用户可输入具体问题，增强占验的针对性
- **直接起卦**：快速起卦，适合日常随机占验
- **一键生成**：六爻同时生成，操作简便流畅

### 2. 结果展示
- **本卦显示**：展示起卦得到的原始卦象
- **之卦显示**：根据变爻自动生成的变化卦象
- **详细信息**：
  - 卦名、卦序号、上下卦组合
  - 六爻详情（爻位、爻象、爻名、随机数）
  - 变爻标识和数量统计
  - 起卦时间记录

### 3. 视觉设计
- **太极图动画**：起卦前的冥想引导界面
- **爻象颜色**：
  - 老阳：红色 (#FF4444)
  - 少阳：橙色 (#FF8800)
  - 少阴：蓝色 (#4488FF)
  - 老阴：紫色 (#8844FF)
- **卦象颜色**：基于五行理论的色彩搭配
- **变爻动画**：变爻闪烁效果，直观显示变化

### 4. 交互体验
- **问卦输入**：支持多行文本输入，记录占验问题
- **动画反馈**：起卦过程中的视觉动画效果
- **结果保存**：显示起卦时间，便于后续查询对照

## 技术实现

### 核心算法
```typescript
// 爻的生成算法
function generateYao(position: number): YaoInfo {
  const randomValue = Math.floor(Math.random() * 100) + 1;
  
  if (randomValue <= 20) {
    // 老阳 (变爻) - 20%概率
    return { type: YaoType.OLD_YANG, symbol: 'O', ... };
  } else if (randomValue <= 49) {
    // 少阴 - 29%概率
    return { type: YaoType.YOUNG_YIN, symbol: '--', ... };
  } else if (randomValue <= 79) {
    // 少阳 - 30%概率
    return { type: YaoType.YOUNG_YANG, symbol: '—', ... };
  } else {
    // 老阴 (变爻) - 21%概率
    return { type: YaoType.OLD_YIN, symbol: 'X', ... };
  }
}
```

### 卦象计算
- **二进制转换**：将六爻转换为二进制数组
- **卦序计算**：基于二进制值计算64卦序号
- **变卦生成**：变爻阴阳转换，生成之卦

### 数据结构
- **YaoInfo**：爻信息接口，包含类型、符号、名称等
- **GuaInfo**：卦信息接口，包含卦名、符号、六爻列表等
- **QiGuaResult**：起卦结果接口，包含本卦、之卦、变爻数量等

## 使用方法

### 基本流程
1. **进入起卦页面**：从汉代象数易学模块进入
2. **选择起卦方式**：
   - 点击"设置问题并起卦"输入具体问题
   - 点击"直接起卦"进行快速占验
3. **观看起卦动画**：等待六爻生成过程
4. **查看结果**：
   - 本卦：原始卦象和六爻详情
   - 之卦：变化后的卦象（如有变爻）
   - 卦象组合：用于查询焦氏易林

### 结果解读
- **无变爻**：以本卦为主进行解读
- **有变爻**：本卦看现状，之卦看趋势
- **卦象组合**：如"乾之履"，可查询焦氏易林对应条目
