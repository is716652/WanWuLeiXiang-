# 京房八宫卦功能说明

## 功能概述

新增了"京房八宫卦"功能，用于展示京房易学中的八宫卦体系，包括世应关系、卦变规律等核心内容。这是六爻占卜和象数易学的基础理论框架。

## 核心概念

### 1. 八宫卦系统
将六十四卦分为八宫，每宫八卦：
- **乾宫八卦**：乾为天、天风姤、天山遁、天地否、风地观、山地剥、火地晋、火天大有
- **震宫八卦**：震为雷、雷地豫、雷水解、雷风恒、地风升、水风井、泽风大过、泽雷随
- **坎宫八卦**：坎为水、水泽节、水雷屯、水火既济、泽火革、雷火丰、地火明夷、地水师
- **艮宫八卦**：艮为山、山火贲、山天大畜、山泽损、火泽睽、天泽履、风泽中孚、风山渐
- **坤宫八卦**：坤为地、地雷复、地泽临、地天泰、雷天大壮、泽天夬、水天需、水地比
- **巽宫八卦**：巽为风、风天小畜、风火家人、风雷益、天雷无妄、火雷噬嗑、山雷颐、山风蛊
- **离宫八卦**：离为火、火山旅、火风鼎、火水未济、山水蒙、风水涣、天水讼、天火同人
- **兑宫八卦**：兑为泽、泽水困、泽地萃、泽山咸、水山蹇、地山谦、雷山小过、雷泽归妹

### 2. 卦序规律
每宫八卦的排列遵循固定规律：
1. **本宫卦（八纯卦）**：世爻在上九
2. **一世卦**：初爻变，世爻在初爻
3. **二世卦**：二爻变，世爻在二爻
4. **三世卦**：三爻变，世爻在三爻
5. **四世卦**：四爻变，世爻在四爻
6. **五世卦**：五爻变，世爻在五爻
7. **游魂卦**：四爻回变，世爻在四爻
8. **归魂卦**：下三爻复原，世爻在三爻

### 3. 世应关系
- **世爻**：代表主体、自己、问卜者
- **应爻**：代表客体、对方、相关事物
- **对应规律**：初四、二五、三上相应

## 功能特性

### 1. 宫位切换
- 顶部横向滚动的宫位选择器
- 点击切换不同的宫位
- 当前宫位高亮显示

### 2. 搜索功能
- 点击顶部🔍按钮开启/关闭搜索
- 支持搜索卦名、宫位、世次
- 实时过滤显示结果

### 3. 信息展示
- 清晰展示每个卦的宫属、世次、卦象、卦名
- 显示世爻和应爻的位置
- 简要说明卦的变化规律

## 使用方法

1. 在首页点击"京房八宫卦"卡片进入
2. 默认显示乾宫八卦
3. 点击顶部的宫位标签切换不同宫位
4. 点击搜索按钮可以快速查找特定的卦
5. 查看每个卦的详细信息：
   - 卦在本宫中的序号
   - 属于哪一世（本宫、一世至五世、游魂、归魂）
   - 卦象和卦名
   - 世爻和应爻的位置
   - 变化规律的简要说明

## 理论依据

### 卦变规律
京房认为六十四卦通过阴阳变化衍生：
1. 从本宫卦（八纯卦）开始
2. 从初爻开始逐爻进行阴阳变化
3. 经过五世后，四爻回变形成游魂卦
4. 下三爻复原形成归魂卦
5. 完成一个完整的周期

### 世应意义
- **世爻**：卦的主体，代表占卜者自身
- **应爻**：卦的客体，代表相关的人或事
- **相应规则**：初四、二五、三上爻位相应

## 注意事项

- 数据基于京房易学传统理论
- 卦序与《周易·序卦传》不同
- 是六爻占卜的核心理论框架
- 每宫八卦的变化规律一致
