# 六十四卦卦数图表功能说明

## 功能概述

新增了"六十四卦卦数图"功能，用于展示六十四卦的象数信息，包括卦象、卦名、先天八卦数以及简义。

## 核心特性

### 1. 数据展示
- **卦序**：1-64的卦序编号
- **卦象**：完整的六十四卦象符号（䷀-䷿）
- **卦名**：如"乾为天"、"坤为地"等
- **上卦数**：上卦对应的先天八卦数
- **下卦数**：下卦对应的先天八卦数
- **简义**：卦的核心含义概括

### 2. 先天八卦数
```
乾1  兑2  离3  震4  巽5  坎6  艮7  坤8
```

### 3. 颜色编码
每个八卦都有专属的颜色标识：
- **乾(1)**：金色 #FFD700
- **兑(2)**：银白 #E8E8E8
- **离(3)**：红色 #FF6B6B
- **震(4)**：青色 #4ECDC4
- **巽(5)**：绿色 #95E1D3
- **坎(6)**：蓝色 #3498DB
- **艮(7)**：黄色 #F39C12
- **坤(8)**：褐色 #8B4513

### 4. 搜索功能
支持通过卦名或简义进行搜索过滤

## 使用方法

1. 在首页点击"六十四卦卦数图"卡片
2. 浏览所有64卦的象数信息
3. 使用顶部搜索框快速查找特定的卦
4. 查看每个卦的详细信息：
   - 卦序和卦象
   - 上卦和下卦的八卦名称及数字
   - 卦的简义说明

## 界面布局

### 顶部说明卡片
显示先天八卦数的对照表，方便快速参考

### 卦数卡片
每个卡片包含：
- **顶部**：序号、卦象、卦名
- **中部**：上卦（名称+数字）、下卦（名称+数字）、卦数组合
- **底部**：简义说明

## 应用场景

1. **易学学习**：系统学习六十四卦的象数关系
2. **梅花易数**：先天八卦数是梅花易数起卦的基础
3. **象数分析**：通过卦数进行数理分析
4. **快速查询**：快速查找某个卦的象数信息

## 特色优势

✅ **直观展示**：卡片式设计，信息一目了然  
✅ **颜色区分**：八卦颜色编码，便于记忆  
✅ **搜索便捷**：支持实时搜索过滤  
✅ **完整数据**：包含全部64卦信息  
✅ **美观界面**：现代化UI设计，使用体验佳

## 注意事项

- 卦数基于先天八卦排序（邵雍梅花易数体系）
- 卦象使用Unicode标准符号
- 搜索功能支持中文卦名和简义关键词
