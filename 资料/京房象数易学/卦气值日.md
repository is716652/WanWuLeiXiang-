### **AI自动生成卦气值日表：核心规则与算法**

#### **第一步：建立基础数据库**

AI内部需要存储以下三个核心数据表：

1.  **《六十值日卦固定顺序表》**
    *   这是京房易学体系下，六十卦（除去四正卦）值日的固定轮转顺序。它不同于《周易》序卦传顺序，也不同于八宫卦序。**（为便于演示，下文将提供一个基于经典记载的推导顺序示例）**
    *   **示例顺序（前12卦）**：中孚、复、屯、谦、睽、升、临、小过、蒙、益、渐、泰 ...（后续48卦按固定规则排列）

2.  **《二十四节气交节时刻表》**
    *   AI需要连接一个天文算法库，能够精确计算**任意年份**的二十四节气交节的**公历日期和具体时间**（精确到分秒）。例如，计算2025年冬至的具体时刻。

3.  **《卦气-物候对应表》**
    *   存储每个值日卦所代表的**理想气候、物候特征**。用于解释和输出。
    *   *例：中孚卦：卦气为“阳气初生，微温”；复卦：卦气为“一阳初生，草木萌动”。*

#### **第二步：确定年度周期的起点**

**规则：以一个“冬至”到下一个“冬至”为一个完整的卦气值日年度周期。**

*   **输入**：用户指定年份（如：2025年）。
*   **计算**：AI调用天文算法，计算出该年**冬至的交节时刻**（如：2025年12月21日 20:30）。
*   **定义**：从此刻起，开启**2025卦气年度**的值日循环。

#### **第三步：计算每卦的精确值日时长**

**采用“六日七分”的现代换算规则：**

*   **定义1日** = 24小时 = 1440分钟。
*   **“七分”的换算**：在汉代，1日=80分。因此，7分 = (7/80) * 24小时 = **2.1小时**。
*   **每卦值日总时长** = 6天 + 2.1小时 = **6 * 1440分钟 + 2.1 * 60分钟 = 8640分钟 + 126分钟 = 8766分钟**。

#### **第四步：生成值日表的推演算法**

这是一个核心的循环算法，AI将按以下逻辑执行：

1.  **初始化**：
    *   `当前时间点 = 2025年冬至时刻`
    *   `当前卦索引 = 0` （从《六十值日卦固定顺序表》的第一个卦“中孚”开始）

2.  **循环推演（循环60次）**：
    *   **当前卦** = `固定顺序表[当前卦索引]`
    *   **当前卦开始时间** = `当前时间点`
    *   **当前卦结束时间** = `当前时间点 + 8766分钟`
    *   **输出记录**：将【卦名、开始时间、结束时间】存入结果列表。
    *   **更新变量**：
        *   `当前时间点 = 当前卦结束时间`
        *   `当前卦索引 = (当前卦索引 + 1) % 60` （实现循环，到第60卦后回到第1卦）

3.  **终止**：循环60次后，即生成完整的60卦值日表，覆盖整个卦气年。

### **规则总结与注意事项**

1.  **确定性**：此规则是**确定性的**。只要《六十值日卦固定顺序表》和天文算法不变，对于同一年份，任何AI生成的表格都将完全一致。
2.  **固定起点**：我们采用了 **“冬至起始，中孚为首”** 的经典说法。历史上可能存在其他流派，但此为最主流和可操作的规则。
3.  **跨年处理**：由于一个卦气年从本年冬至开始，到次年冬至结束，所以生成的表格会**自然跨年**。例如“2025卦气值日表”实际上覆盖了2025年冬至至2026年冬至的时段。
4.  **四正卦不参与**：坎、离、震、兑四正卦作为框架，主管24节气，不在此每日轮值的60卦之中。
