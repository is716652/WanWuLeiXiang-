# 京房重卦法表格功能说明

## 功能概述

京房重卦法表格页面以标准表格形式展示京房易学的八宫卦体系，清晰呈现卦变规律和阴阳消长过程。

## 主要功能

### 1. 理论说明
- 重卦法基本原理
- 卦变规则说明（初爻→二爻→三爻→四爻→五爻）
- 游魂卦和归魂卦的特殊规则

### 2. 宫位选择
- 八宫切换器（乾、震、坎、艮、坤、巽、离、兑）
- 五行配色系统
  - 乾宫、兑宫：金色 (#d4af37)
  - 震宫、巽宫：木色 (#4a7c59)
  - 坎宫：水色 (#1e3a8a)
  - 离宫：火色 (#dc2626)
  - 艮宫、坤宫：土色 (#ca8a04)

### 3. 表格展示
每个卦的信息包括：
- **序号**：在本宫中的序号（1-8）
- **世次**：本宫卦、一世至五世卦、游魂卦、归魂卦
- **卦象**：Unicode卦象符号
- **卦名**：标准卦名
- **世爻**：主体爻位
- **应爻**：客体爻位
- **简释**：卦变说明

### 4. 配色系统

#### 世次标签配色
- 本宫卦：深蓝色 (#1a237e)
- 游魂卦：红色 (#C62828)
- 归魂卦：绿色 (#2E7D32)
- 一至五世卦：蓝色 (#0277BD)

#### 表格颜色
- 表头：对应宫位的五行颜色
- 世爻：蓝色 (#1565C0)
- 应爻：绿色 (#2E7D32)

## 技术实现

### 数据模型
使用 `JingFangData.ets` 单例模式，包含：
- 八宫共64卦数据
- 世应关系数据
- 宫位分类方法

### 页面文件
`JingFangTablePage.ets` - 表格展示页面

### 核心方法
```typescript
// 切换宫位
switchGong(gong: string): void

// 获取五行颜色
getGongColor(gong: string): string

// 获取世次配色
getShiCiBgColor(shiCi: string): string
```

## 京房重卦法理论要点

### 卦变规律
1. **本宫卦**：八纯卦，作为一宫之首
2. **一世卦**：初爻变化
3. **二世卦**：二爻变化
4. **三世卦**：三爻变化
5. **四世卦**：四爻变化
6. **五世卦**：五爻变化
7. **游魂卦**：四爻回变，象征灵魂游荡
8. **归魂卦**：下三爻复原，象征灵魂回归

### 世应关系
- 初爻世应四爻
- 二爻世应五爻
- 三爻世应上爻

### 阴阳变化原则
- 阳爻变阴爻
- 阴爻变阳爻
- 逐爻进行变化

## 与现有功能的区别

### 京房八宫卦页面（JingFangPage）
- 卡片式展示
- 重点展示世应关系
- 适合详细查看单个卦信息

### 京房重卦法表格（JingFangTablePage）
- 表格式展示
- 重点展示卦变规律
- 适合对比和学习整个宫的变化过程
- 更简洁直观

## 使用建议

2. **研究者**：对比分析各宫卦变特点
3. **占卜实践者**：快速查找世应关系
